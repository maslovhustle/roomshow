roomshow

Point a camera at the room, restyle it live, project it back. Runs entirely in the browser.

1 Start a session

Open the stage on the machine wired to the projector, then open the remote on your phone.

2 Link your phone not linked

The remote talks to the stage over a free Supabase Realtime channel. No tables, no schema — just a message bus. Create a project at supabase.com, then copy its URL and anon key from Project Settings → API Keys. Both stay in this browser's localStorage.
